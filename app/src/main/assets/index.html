Real Device App Bridge

When enabled on your phone, launching apps like Dialer (`tel:`), Messages (`sms:`), Mail (`mailto:`), Maps (`geo:`), or Browser (`https:`) triggers your phone's real installed apps directly.

Method 1: Fullscreen Web App (Fastest • 30 sec)
  1. Download this HTML file (or host it free on GitHub Pages / Netlify Drop).
  2. Open the link in Chrome (Android) or Safari (iOS).
  3. Tap Browser Menu (⋮ or Share) → Add to Home Screen.
  4. Launch it from your home screen—it opens borderless without browser bars.
Method 2: Default Home Button Replacement (Android)

Android requires a native APK with CATEGORY_HOME in AndroidManifest.xml to replace your system launcher when pressing the Home button. You can wrap this HTML file in WebAPK / Cordova / Android Studio WebView or use Fully Kiosk Launcher pointing to this file.
